## Qué es

Este es un documento de concepto, no un programa terminado. Discute cómo sería un sistema en el que personas, agentes de IA (como Claude Code y Codex) y bots de Telegram comparten los mismos canales, como en un chat de equipo. Hoy cada uno usa la IA solo; la idea es que todo el equipo, humanos y agentes, trabaje junto y vea todo lo que está pasando. Sirve para quien quiere pensar este modelo para uso propio, para empresas o para juegos. Solo hay que leer: cada página trae posibilidades, riesgos y las fuentes consultadas.
